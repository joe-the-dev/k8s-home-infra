# Explain a Kubernetes Resource

Given a K8s resource type or manifest, explain:
1. What it does and why it exists
2. Key fields and what they control
3. How it relates to other K8s objects
4. A simple real-world analogy

If the user provides a filename or YAML snippet, explain the specific manifest.
If the user provides just a resource type (e.g. "Deployment", "Service", "Ingress"), give a general explanation with a minimal home-lab example.

Always tie explanations back to home lab use cases where relevant.
